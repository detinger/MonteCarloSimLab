# Chart series

The first three series use the colors specified in STYLE.md. Four through eight add purple, ochre, teal, rose and slate with brighter dark-theme counterparts. The CSS values are in src/styles/tokens.css. Individual paths retain their series index and dash pattern when selected. The path selector, endpoint summaries and data download provide a numerical way to inspect a trajectory.

Analytical benchmarks use dashed reference lines and text. Confidence intervals report their estimator and method. Simulated quantile bands describe the distribution of paths at a given time. Distribution Studio compares the sample share of a bin with its theoretical probability mass, so both measurements use the same units.
